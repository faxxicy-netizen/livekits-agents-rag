# 服务器部署与维护

本文使用 `203.0.113.10` 作为示例地址，部署时请替换为自己的公网 IP 或域名。

部署日期：2026-10-19。实例为 OpenCloudOS 9.6、2 vCPU、2GB 内存、40GB 系统盘。

入口：<http://203.0.113.10/>，自动跳转至 <https://203.0.113.10/>。使用约定的演示密码登录；本文不保存密码或 API Key。

## 实际运行结构

- ASR：阿里云 `qwen-audio-3.1-asr-flash-streaming`，原生 WebSocket。
- TTS：阿里云 `qwen-audio-3.1-tts-flash`，`yuxiaoyun_v3.1`，原生 WebSocket 流式音频。
- LLM：外部 DeepSeek `deepseek-flash`，关闭思考、SSE 逐句输出。沿用用户原先指定的服务，没有换成另一家 LLM。
- Embedding：阿里云 `qwen3.7-text-embedding-flash`，1024 维，OpenAI 兼容 embeddings 接口。
- Qdrant、SQLite、LiveKit、FastAPI 和编译后的网页都在此服务器。Nginx 提供 HTTPS 和 WebSocket 反向代理；前端由 FastAPI 提供，不启动 Node 开发服务器。
- 依赖仅安装云端所需的 91 个锁定包，没有安装 PyTorch、Transformers、Kokoro、SenseVoice。Silero VAD 是轻量 CPU 组件，仍在 Agent 中负责本地语音活动检测。
- 没有预热空闲 Agent 子进程，按需启动，允许同时一通演示电话。首次连接欢迎语会包含 Agent 初始化时间。

## 启停与日志

服务已设置开机自启，服务器重启后不用逐项手工启动。

```bash
systemctl status support-qdrant support-livekit support-api support-agent nginx
systemctl restart support-api support-agent       # 修改模型配置后重启
systemctl stop support-agent support-api           # 暂停体验；Nginx/数据库可继续运行
systemctl start support-api support-agent
journalctl -u support-api -u support-agent -f
```

API 启动前等待 Qdrant 就绪；Agent 启动前等待 API 健康检查。`/healthz` 是不调用模型的公开存活检查，其余页面、文档接口、聊天、检索和语音令牌接口均由后端密码门禁保护。

登录密码使用 PBKDF2 哈希保存，登录会话使用签名、HttpOnly、Secure、SameSite cookie，有效期8小时。登录失败有每来源与全局尝试限额，防止无限尝试。更换密码哈希后旧登录 cookie 自动失效。LiveKit 使用本次部署生成的随机独立凭据，房间令牌有效期10分钟。

## 网络与证书

腾讯云实例防火墙已由用户放行 TCP 80、443、7881，UDP 7882，并保留 SSH 22。80 只用于跳转与 ACME 验证；443 提供可信网页/WSS；7881/7882 承载 WebRTC 媒体，不能只开放网页80。

已通过 Let's Encrypt 申请 IP 地址证书，首次证书到期日期为2026-10-26。此类证书有效期约6天，已配置每天两次检查续期、续期成功自动 reload Nginx：

```bash
systemctl status support-cert-renew.timer
systemctl list-timers support-cert-renew.timer
journalctl -u support-cert-renew.service
```

服务器增加1GB应急 Swap，常规运行不依赖 Swap 推理。修改机器公网 IP 后需要重新申请对应 IP 证书，并修改 Nginx、`APP_PUBLIC_ORIGIN`、`LIVEKIT_PUBLIC_URL`。

## 本次验证与边界

- 公网80正确跳转，HTTPS证书验证通过；匿名业务接口401，正确密码登录成功，安全 cookie 生效。

## 重新安装说明

安装服务前设置公开访问地址，例如 `sudo env PUBLIC_HOST=203.0.113.10 bash deploy/install-services.sh`。`PUBLIC_HOST` 应与已申请的证书名称、`APP_PUBLIC_ORIGIN` 和 `LIVEKIT_PUBLIC_URL` 一致。

`deploy/bootstrap.sh` 安装系统依赖和工具，`deploy/install-services.sh` 创建 systemd、Nginx 和证书续期配置。脚本不包含密钥；还需要独立准备服务器 `.env`、LiveKit 随机凭据配置、编译后的前端和数据库备份。GitHub直连在本次服务器上下载不稳定，因此正式二进制从本机的官方 GitHub Release 下载后传入服务器。Python依赖使用仓库 lock 导出，再通过阿里云 PyPI 镜像安装；服务器不执行默认包含本地模型组的 `uv sync`。

```powershell
uv export --frozen --no-default-groups --no-hashes --no-emit-project --format requirements-txt --output-file runtime/server-requirements.txt
```

```bash
uv pip sync --python /opt/support-agent/.venv/bin/python \
  --index-url https://mirrors.aliyun.com/pypi/simple /opt/support-tools/server-requirements.txt
```
